# RapidStudy Admin Panel

Administrative interface for managing content and users.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Configure environment:
```bash
cp .env.local.example .env.local
```

3. Run development server:
```bash
npm run dev
```

4. Open [http://localhost:3001](http://localhost:3001)

## Build

```bash
npm run build
npm run start
```

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Axios
- React Hook Form + Zod

## Features

- User Management
- Exam Management
- Question Bank
- Test Builder
- Analytics Dashboard
- Question Import (CSV/XLSX)
- AI Question Generation
